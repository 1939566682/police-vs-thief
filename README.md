# 🚨 警匪追逐 · 实时互动对战游戏

精美的实时对战网页游戏:**观众点击“加入警察 / 加入小偷”即可参战** — 完整的阵营分配、积分赛制、六种道具、追逐攻防与明确的胜负判定,每一局自动开赛,未加入的观众可以全程观战实况。

## 快速开始

```bash
cd police-vs-thief
npm install
npm start          # 等价 node server.js
```

打开浏览器访问 **http://localhost:3000** (可用 `PORT=8080 npm start` 换端口)。

多人联机:同一局域网内的手机/平板访问 `http://<电脑IP>:3000` 即可加入同一战场(电脑 IP 用 `ipconfig` 查看)。

> 服务端启动即自动开赛(双方各 4 名 AI 机器人保底),观众随时加入,观战与参战自由切换。

## 玩法

| 项目 | 说明 |
|---|---|
| 阵营 | 点击「加入警察 / 加入小偷」自动入队,顶栏实时显示**双方人数与积分**,退出可随时换边 |
| 积分 | 警察每抓获一名小偷 +1;小偷每盗走一枚金币 +1;道具可通过**消耗积分**立即兑换 |
| 胜利 | **率先达到 10 分**、**警察全歼小偷**,或**时间到积分领先** → 对战结束弹出结算(胜负/MVP/战绩榜),12 秒后自动开启下一局 |
| 时间 | 每局 100 秒 |

## 道具系统(每方 3 种)

键盘 **1 / 2 / 3** 或点击右下角道具按钮;冷却好直接触发,冷却中可点按钮**消耗积分立即释放**(按钮出现 ⚡ 闪光)。

### 警察 👮
| 道具 | 效果 | 冷却 / 兑换 |
|---|---|---|
| ⛓️ 手铐 | 向瞄准方向投掷,命中后禁锢小偷 2.6 秒;瞄准方向 **±26° 内有可见小偷时自动吸附修正弹道**(含速度预判),更容易命中 | 9s / 3 分 |
| 🐕 警犬 | 放出警犬自动追踪最近小偷,持续减速追击 | 16s / 5 分 |
| 🚧 路障 | **预览式放置**:首次按 3 / 点击按钮进入预览,幽灵路障跟随鼠标,可放处绿色、不可放处红色(含放置点与两端判定);左键或再次按 3 在鼠标处放置,**非法位置确认会直接取消且不扣冷却/积分**;右键 / Esc 随时退出预览 | 15s / 4 分 |

### 小偷 🦹
| 道具 | 效果 | 冷却 / 兑换 |
|---|---|---|
| 💨 烟雾弹 | 脚下生成烟雾屏障:烟雾内免疫抓捕,且遮挡警察视线(隔烟不可抓) | 11s / 3 分 |
| ⚡ 疾跑 | 3.4 秒 72% 加速冲刺(带残影);**无法挣脱手铐禁锢** | 12s / 2 分 |
| 🎭 伪装 | 7 秒伪装成路人:警察无法抓捕/瞄准,靠近太久才会被识破 | 17s / 5 分 |

## 操作

**桌面端**:WASD / 方向键移动,鼠标瞄准(手铐、路障投掷方向),1 / 2 / 3 放道具;**路障为预览式**:按 3 出现跟随鼠标的幽灵路障(绿=可放,红=不可放),左键或再按 3 确认,右键 / Esc 取消;点击道具按钮可在冷却中积分兑换。

**移动端**:左侧虚拟摇杆移动;右侧道具按钮,冷却中点按钮消耗积分立即释放;指哪打哪(手铐朝移动方向投掷)。

## 规则细节

- 金币**不再走过去免费捡**:小偷需贴近金币站桩 0.8 秒完成盗取(脚下显示金色读条),离开范围或被抓即中断——警察有真实的拦截窗口;伪装状态下偷钱会**当场暴露伪装**。
- 警察与小偷身体接触即**抓获**:被抓的小偷原地冻结 1.2 秒后回贼窝重生,带 2.2 秒保护闪烁。
- **手铐禁锢期间小偷无法使用任何道具**(疾跑/烟雾弹/伪装均不可),手铐命中即稳定缉拿窗口;想逃只能等禁锢结束。
- 烟雾弹同时**阻挡追踪**:烟雾内的小偷无法被警犬锁定、手铐命中(飞行途中进烟也会失效)。
- 路障为**预览式放置**(见道具表),两端与中心任一撞墙即红色不可放,确认失败不扣任何消耗;手铐撞墙/穿烟即消散。
- 掉线玩家由 AI 自动接管,战场人数不减;重连自动回到原阵营。
- 观战者视角为全地图俯瞰,参战者视角自动**跟随缩放**。

## 项目结构

```
police-vs-thief/
├─ server.js          # 服务端: WebSocket 权威模拟(30Hz 物理/道具/胜负) + 静态托管
├─ public/
│  ├─ index.html      # 游戏页面(无构建, 原生 JS)
│  ├─ css/style.css   # 夜城主题 UI
│  └─ js/
│     ├─ map.js       # 共享地图(服务端碰撞 / 客户端绘制单一真源)
│     ├─ render.js    # Canvas 渲染: 夜城地图、角色、金币、道具特效、飘字
│     ├─ ui.js        # 计分板 / 道具栏 / 事件播报 / 加入面板 / 结算弹窗
│     ├─ input.js     # 键盘 / 鼠标 / 触屏摇杆
│     ├─ net.js       # WebSocket 自动重连
│     ├─ state.js     # 快照插值 / 事件与音效
│     ├─ audio.js     # WebAudio 合成音效(无需素材)
│     └─ main.js      # 主循环
└─ test/smoke.js      # 协议冒烟测试(15 项断言)
```

## 测试

```bash
PORT=3101 node server.js --test &   # 测试模式: 开启 dev 指令(end/score/tp)
SMOKE_URL=ws://localhost:3101 node test/smoke.js     # 协议冒烟 15 项
node test/balance.js                                  # 平衡性验证(需 3101 已启动)
```

## 调参

所有玩法参数集中在 `server.js` 顶部 `TUN` 常量:对局时长、目标分、移动速度、抓捕半径、六种道具的冷却/消耗、机器人数量等,`--test` 启动时可用 `{t:'dev',k:'end',w:0|1}` 强制结算测试。
